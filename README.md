# Visual Graph OS / Neuro

A strategy-training app for mapping opportunities, separating evidence from assumptions, scoring execution readiness, and building a daily map -> predict -> act -> review habit.

## Product base

The current UI direction is the V6 standalone app shell:

- dark command-center layout
- saved maps
- daily rep streak
- opportunity mapping
- power, money, authority, access, pain, volume, blockers, clean win
- evidence versus assumption filter
- action commitment
- prediction and outcome review
- weighted scoring
- reality lock and red flag gates
- visual node map
- backup, import, and markdown export

## Backend direction

Use Supabase for cloud history:

- maps
- map_versions
- prediction_reviews
- daily_reps
- vgos_activity_log

## Rule

The history is the product. The map is only the surface.
